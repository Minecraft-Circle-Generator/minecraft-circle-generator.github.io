# Minecraft Circle Generator ⛏️⭕

> Generate pixel-perfect circles, ovals & spheres for your Minecraft builds — free, instant, no install.

## ✨ Features

- ⭕ **Circles & Ovals** — Independent width/height controls for ellipses
- 🎯 **Pixel-Perfect** — Midpoint circle algorithm for accurate block placement
- 🔄 **3 Fill Modes** — Hollow, Thick, and Filled circles
- 📊 **Real-time Block Count** — Know exactly how many blocks you need
- 📸 **PNG Export** — Download your circle chart as a high-res image
- 📋 **Copy Layer Data** — Layer-by-layer block counts for clipboard
- 📱 **Mobile Friendly** — Works on any device, any screen size
- 🔒 **100% Private** — Everything runs in your browser. No tracking.

## 🎮 How to Use

1. **Set diameter** with the slider (3-128 blocks)
2. **Choose fill mode** — Hollow, Thick, or Filled
3. **Read the grid** — Each green cell = one Minecraft block
4. **Export or Copy** — Save as PNG or copy layer data
